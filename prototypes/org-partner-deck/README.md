# Virtual Closet deck

A ten-slide deck for first calls with LGBTQ+ centres about the Virtual Closet programme. Vertical slides, one idea each; arrow keys, space, or the corner buttons move between them.

- `template.html` is the source; `index.html` is built by replacing `{{IMG_JSON}}` with the base64 image map from `../org-closet-page/img` (same build as the closet page).
- Open `index.html` in a browser and share the window. Works offline apart from the web fonts.
- Language rule: matching, never discount or wholesale. The Virtual Closet is described as a pilot the centre can be first on; the donation programme and matched purchasing are described as running today.
- Companion page for the live demo: `../org-closet-page/`.
