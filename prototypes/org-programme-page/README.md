# Virtual Closet programme page

A one-page description of the Virtual Closet for LGBTQ+ centres: the gap, the three doors, the terms in one table, a worked example of a single box, what we ask, and how to start. Converted from the deck in `../org-partner-deck/`.

- `template.html` is the source; `index.html` is built by replacing `{{IMG_JSON}}` with the base64 image map from `../org-closet-page/img`.
- Language rule: matching, never discount or wholesale. Numbers match `.claude/plans/org-closet-programme.md`: 20% off code, 25% credit, $300 box = $600 product, $10 shipping per package charged to the box, two requests a year per person, free pairs final.
- "See a centre's page" links to the closet page artifact; share that artifact before sending this page to a centre.
